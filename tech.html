// démo, pilotez l'agent

Donnez-lui une mission. Regardez-le travailler. Regardez-le le prouver.

L'agent (GLM-4.5-flash, un modèle free) réfléchit, appelle navette_navigate pour lire une vraie page web, puis scelle sa conclusion avec noirebox_note. Tout s'affiche ici, y compris les hash. Astuce : cliquez n'importe quelle cellule de la matrice ci-dessus, l'agent ira l'inspecter.

Le serveur de l'agent est éteint, le reste du site marche sans lui. Pour la démo : npm install && npm start dans le dossier du site (il démarre navette tout seul). Aucune donnée n'est envoyée nulle part tant qu'il est éteint.

// ce que je fais

Six métiers, une exigence : que ce soit vérifiable.

Du poste de lead à la conformité réglementaire, la même approche : on prouve, on ne promet pas.

01

Développement

Lead full-stack : PHP/Symfony, TypeScript, Python, Rust, Dart, Swift. Web, API, mobile. Audit, refonte, greenfield. Maintenabilité d'abord, le code que je laisse derrière moi doit rester vivant.

02

Agents IA

Architecture et mise en production de systèmes d'agents : outillage, garde-fous, observabilité. Du prototype qui impressionne au service qui tient le lundi matin.

03

CI/CD & plateforme

Pipelines GitHub Actions, Docker, automatisation de bout en bout, jusqu'à l'admin Microsoft 365 et AD. Des flottes d'agents sur des runners gratuits, des releases qui partent seules, des tests qui bloquent les mauvaises surprises.

04

Sécurité & audit

Revue de code forensique, chasse aux failles, durcissement. RCE signalées et corrigées dans l'open source, audits d'infra, secrets qui fuient, je trouve avant les autres.

05

Conformité par la preuve

AI Act en force, RGPD au quotidien. Rendre la conformité vérifiable : journaux chaînés, receipts scellés, provenance des décisions. Livrables auditables, pas des slides.

06

Transmission

Formation et mentorat : Git, Symfony, debugging, sécurité. Cours, ateliers, montée en compétences d'équipes. Ce qui se comprend se transmet, sinon c'était du cargo cult.
