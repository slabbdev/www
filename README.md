# slabb.dev, a sealed website with a live agent demo

Static site, zero dependencies, zero build, zero tracking. And the whole thing is **sealed**: every file is hashed (SHA-256), the hashes are chained, and the chain head is signed with **Ed25519**, see "The seal" below.

## Pages

- `index.html`, the gate: two doors, *tech* or *not at all*.
- `tech.html`, the single page: six trades, an interactive proof lab (live SHA-256 chain + the 200-URL benchmark matrix with real data), the stack, a filterable career timeline, products, writing, contact. FR/EN toggle, auto-detected.
- `client.html`, the plain-language version for non-technical visitors. FR/EN.
- `verify.html`, in-browser verification: WebCrypto SHA-256 per file, chain rebuild, Ed25519 signature check.
- `verify.py`, out-of-band verification against any deployment: `python3 verify.py https://slabb.dev` (stdlib only, RFC 8032 self-test).
- `manifest.json`, `pubkey.b64`, `seal-journal.jsonl`, the public seal, generated by `tools/seal.py`.
- `replay.json`, real recorded agent runs (FR + EN), replayed as-is on static hosting.
- `journal.jsonl`, snapshot of the agent journal at build time.

## Run the agent locally

The agent demo lives inside `tech.html`; it is hidden until a server is running:

    npm install
    npm start        # serves the whole site + the agent API on :8791, spawns navette

Requires a model key (`ZAI_API_KEY`) and the navette browser binary (`NAVETTE_BIN` or `NAVETTE_URL`). Without a key, the section says so plainly.

## The seal

    python3 tools/seal.py        # hashes + chain + Ed25519 signature + manifest
    python3 verify.py .          # must end with "INTÈGRE / INTACT"

Re-run before every deploy. The private key never leaves the machine; the public fingerprint is published out-of-band: `sha256:5d7e19291be7eb6b`.

## Deploy

    ./deploy/pages.sh            # builds dist-pages/ (static + journal snapshot, sealed, verified)
    ./deploy/publish.sh          # same, then commits and pushes to this repository

Served at https://slabb.dev via GitHub Pages.
